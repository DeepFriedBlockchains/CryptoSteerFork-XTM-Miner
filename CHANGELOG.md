
# Changelog

## 2.2.1

- Added the final CryptoSteer launcher and store artwork.
- Added the F-Droid build type and public store metadata.
- Disabled the private updater and anonymous installation/mining telemetry in F-Droid builds.
- Added a dedicated monochrome notification icon.
- Improved mandatory-update verification and retry behavior.
- Added Live, 5 minute, 15 minute, 1 hour, and Session hashrate views.
- Improved installation counting and near-live telemetry.
- Added deterministic source archives and pinned native source publication.
- Updated legal and licensing material for THE CRYPTO STEER LLC.

## 2.1.2

- Preserved mandatory-update enforcement across temporary verification failures.
- Added a visible update-verification error state and retry action.
- Added periodic update checks while the application is open.

## 2.1.1

- Added selectable hashrate history windows.
- Updated the About screen and public product wording.
- Improved installation and active-mining statistics.

## 2.0.2

- Initial public direct-distribution release of the native Android miner and optional control features.
