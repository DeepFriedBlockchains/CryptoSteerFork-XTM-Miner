
# Security policy

Security reports should be sent privately to:

```text
dev@thecryptosteer.com
```

Include the affected version, device and Android version, reproduction steps, impact, and any supporting logs with credentials removed.

Do not publish an unpatched vulnerability, private key, token, password, recovery code, or personal user data in a public issue.

The maintainers will confirm receipt, assess the report, and coordinate a fix and disclosure schedule when the report is valid.
